# 操作說明

ACGATool 配合中文維基百科的維基ACG專題獎登記頁與積分頁運作。
在專題獎主頁、登記頁、一般條目及其討論頁使用「工具」側欄中的
**提名至ACG專題獎** 入口；從條目或討論頁啟動時，工具會自動帶入對應的條目名稱。
在登記頁面使用各提名旁的編輯或核對按鈕，以及日期段落旁的歸檔按鈕。
檔案頁及圖片預覽會自動選擇項目 6，並建議最後上傳者為得分者。
從固定版本或版本差異頁啟動時，會建議該版本編輯者；項目 7 仍使用工具
使用者本人。讀取建議得分者時會顯示「...」，也可自行填入得分者。

## 提名與計分

填入條目標題、作者及適用的得分理由。工具會依據內容擴充、品質、評選、
專題活動等規則計算分數。作者與理由仍應由使用者核對；工具會依填入資料
產生登記頁的維基文字。

每項提名只能選擇一組規則：**1–4、5、6、7 或 8**。同組內可依規則填寫
適用項目；不同組的貢獻請分開提名。新增、編輯、核對及重建理由使用相同的
分類方式。

新增提名時，表格分頁及各表格內的項目分頁會一直顯示；使用「新增表格」
可加入另一組提名。切換分頁會保留各表格的草稿，每個表格可在彙總時填寫
自己的附加說明，提交後會各自形成提名表。
刪除表格的最後一項會移除該表格；整批至少須保留一項提名。

已有提名提示會列出目前登記處的相關提名；同一得分者與對象會出現較明確的
重複計分提示。請比較得分項目及貢獻內容，避免將不同貢獻誤判為重複提名。
核對含 DYK 得分項目的提名時，「DYK狀態」會顯示從討論頁讀取的最近一次
提名主編、通過或未通過結果，以及結束日期；未找到記錄及讀取失敗會分別
提示。這些資訊不會自動勾選得分項目。

已有核對結果的提名會顯示「複核」，可調整評分後再提交。積分榜只會增減
新舊結果之間的差額；降低得分時會扣除相應分數，編輯摘要會標示複核。
「修改提名」位於獨立置中的一行，「核對」或「複核」則接在核對文字後。
條目、作者及外部讀取結果
會以文字呈現，避免將頁面內容當作介面程式碼執行。
若原始理由無法解析，可使用完整提名表單重建理由，並修正得分者及條目。

## 暫存與提交

新增或編輯提名時，表單變更先保存在本地草稿，儲存後才寫入登記頁。
批次核對會暫存各項核對結果，完成整批後才對登記頁及積分榜各執行一次編輯。
在提名旁按下「加入批次核對」即可選入批次，再按一次即可取消選取。
選取任一項後，各提名的「核對」按鈕會改為「批次核對」，按下即可核對已選取的提名。
取消所有選取後，按鈕會恢復單項核對；頁首不再另設工具列。
批次對話框以表格分頁及表格內的項目分頁導覽；切換分頁或按「上一項」會
保留各項草稿。按「下一項」會暫存目前結果，「跳過」會移除該項已暫存的
結果。完成全部項目後按「儲存全部」提交整批；「退出」則只提交已完成的
結果並關閉，尚未完成的項目不會寫入。取消核對會放棄整批尚未提交的結果。

核對表格標題旁有復原、重做及重置；每列的重置圖示位於垃圾桶圖示前。
重置會還原該列或整張表的原始核對項目，並可透過復原找回修改。
附加說明位於表格頁尾，也可復原及重做。完成前請留意進度及結果訊息。

兩個維基頁面的編輯無法組成同一筆交易。若其中一頁成功而另一頁失敗，
請依介面的部分成功訊息處理，並核對兩頁的最新內容，避免重複計分。

## 安裝與更新

`acga_tool.min.js` 適合貼入個人 `common.js` 或作為站點小工具。
`acga_tool.user.js` 適合由 Tampermonkey 安裝。
請只啟用其中一種載入方式，以免重複建立控制項。
