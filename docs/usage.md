# 操作說明

ACGATool 配合中文維基百科的維基ACG專題獎登記頁與積分榜運作。
在登記頁、條目、討論頁或檔案頁，使用頁面工具中的
**提名至ACG專題獎** 入口。登記頁另有逐項編輯、核對及日期段落歸檔按鈕。

## 提名與預覽

每項提名選擇 **1–4、5、6、7 或 8** 中的一組規則，再填入得分者、對象
及適用的得分理由。項目 5 提供一般、專項及綜合評審模式，可調整各列理由
與分數。新增、編輯及核對使用相同分類；使用者負責確認作者與貢獻內容。

條目與討論頁自動帶入條目名稱；條目提名可建議過去一年增添位元組最多的
貢獻者。檔案頁與圖片預覽預選項目 6，建議最後上傳者；固定版本與差異頁
建議該版本編輯者，項目 7 使用目前使用者。建議讀取中顯示「...」；自行
填入的值優先，空白欄位在驗證與提交時使用目前顯示的預設值。

表格分頁包含各自的項目分頁，切換會保留草稿。新增項目或表格前會驗證
目前項目；刪除最後一項會移除該表格，整批至少保留一項提名。
拖曳項目分頁可調整順序，拖到其他表格分頁可移入該表格，拖到表格列的
「+」可移到新表格。拖曳保留未完成及凍結的草稿；Shift 加方向鍵可調整
項目順序，Shift 加 Home 或 End 可移到首尾。調整後的順序會保留於暫存。
彙總可逐項編輯、凍結或恢復提名，並填寫各表格的附加說明。凍結項目保留
草稿，預覽及提交只包括啟用的項目；整批至少須有一項有效提名。
每張提名表最多 25 項，超過時會自動分表並保留說明。

「預覽」會解析整批維基文字，確認後按「儲存」提交。預覽與提交使用相同
批次內容。原始理由無法解析時，可使用完整提名表單修正得分者、對象及理由。

## 提名資訊

項目 1–4、5、6 會查找登記處的已有提名；得分者與對象都相同時顯示可能
重複的提示及連結。請比較實際得分項目與貢獻內容。

條目輸入框下方以灰字顯示頁面評級與 DYK 資訊，核對時則放在摘要中。
評級按品質排序，同組的 ACG、動畫、漫畫及電子遊戲專題優先並以粗體顯示。
DYK 提示包含最近一次提名主編、結果及結束日期；無記錄時顯示「近期無DYK記錄」，
整段文字連結至討論頁。入選日期另顯示相隔天數
與討論頁連結。當前 DYK 提名提供候選頁連結。缺少記錄及讀取失敗會分別
提示；這些資訊供人工核對，得分項目由使用者選擇。

## 瀏覽器暫存

新增提名的表單、彙總及預覽都有「暫存」按鈕，通過與預覽相同的驗證後
儲存整批草稿並關閉視窗。驗證失敗會保留視窗及原有暫存資料。

在同一瀏覽器、站點與帳號重新開啟入口，會還原表格、各分類輸入、說明、
凍結狀態及原有預設值。從新的條目或檔案頁開啟，會新增並選取該頁的提名；
從已有項目的頁面或登記處開啟，會回到原本位置。彙總或預覽暫存後回到彙總。

開啟中的視窗會自動合併其他分頁的草稿，保留正在輸入的內容及目前項目。
例如 A 頁暫存後，已開啟的 B 頁會載入 A，並保留 B 的本地提名。
彙總會自動更新；預覽內容過期時返回最新彙總。編輯彙總項目期間，合併會
等到完成或取消該項編輯。返回瀏覽器分頁時也會讀取最新草稿。

「暫存」更新瀏覽器資料，「儲存」提交到維基。成功提交後清除已提交且
版本相符的草稿，保留凍結項目及其他分頁的較新變更。提交失敗保留草稿；
取消視窗放棄本次未暫存的變更，原有暫存仍可還原。每個帳號在同一站點共用
一批草稿，資料保存在目前瀏覽器與裝置。

## 核對與複核

登記頁的核對按鈕供其他使用者確認提名；提名者及得分者的按鈕會停用並
說明原因。已有核對結果的提名使用「複核」，積分榜依新舊結果的差額調整。

待核對項目可勾選「加入批量核對」後使用「批量核對」，取消所有選取後
恢復單項核對。「加入批量核對」不可用時，核取方塊及文字會顯示為灰色。
已核對項目只提供單項「複核」按鈕，無須勾選；進入批量核對模式後會停用
複核，取消所有選取後恢復。

首次核對預設勾選所有得分列，請依實際貢獻調整勾選、理由與分數；複核
保留已儲存的勾選結果，不會重新全選。

批次對話框以一列連續編號的項目分頁導覽，切換分頁及「上一項」保留各項
草稿與歷史。頁尾橫排按鈕依序為「取消」、「上一項」、「暫不核對」及
「下一項」或「儲存全部」。「下一項」接受並暫存目前結果，「暫不核對」
移除該項已接受的結果。修改已接受的項目後，須再次接受才納入提交。
核對表格提供復原、重做、逐列重置及整表重置，附加說明位於頁尾並共用歷史。

按「儲存全部」完成整批時，會提交已接受的結果並關閉；對最後一項待核對
提名選擇「暫不核對」也會完成整批並提交其他已接受的結果。若沒有已接受的
結果，則直接關閉而不提交。「取消」放棄整批暫存結果並關閉。
暫不核對的項目保持未核對狀態。
提交會對登記頁與積分榜各執行一次編輯。
寫入登記頁前失敗時保留視窗；登記頁成功後會關閉核對，並回報積分榜結果。
若積分榜更新失敗，請依部分成功訊息核對兩頁的最新內容，再處理剩餘更新。

## 歸檔與安裝

日期段落中的每項提名皆須已完成核對，且最後核對已超過七天，才可歸檔。
待核對、正在複核或日期未明的段落會停用歸檔。討論也超過七天時，歸檔按鈕
使用強調樣式；較新討論使用一般樣式。提交前會再次驗證來源與頁面版本。

`acga_tool.min.js` 適合個人 `common.js` 或站點小工具；
`acga_tool.user.js` 適合 Tampermonkey。選擇一種載入方式即可。
