# ACGATool

專案頁面：[ACGATool](https://zh.wikipedia.org/wiki/User:SuperGrey/gadgets/ACGATool)

[維基ACG專題獎](https://zh.wikipedia.org/wiki/WikiProject:ACG/維基ACG專題獎) 專用提名、核分小工具。

- **同時編輯：** 新提名、既有提名修改、核對／覆核可同時進行，最後一起送出。既有提名只有產生實際變動才計入操作。新提名不限筆數，放在登記處最底下，按 UTC 預覽接續當天小節或新增日期標題。頁首「登記新提名」與標題 editsection 裡的「歸檔」維持原有位置；正文容器末尾另有一個「登記新提名」，新表單放在此按鈕之前，懸浮條不再重複提供「新增一筆」。
- **逐筆取消與暫存：** 每類操作都可取消及暫存；懸浮條的「全部暫存」會一次移入所有可編輯表單，已送出而尚未儲存完成的操作仍留在儲存流程中。新提名的垃圾桶旁顯示「刪除」，用於丟棄該筆未提交內容；修改及核對表單使用「取消」。暫存按鈕搭配順時針旋轉 90° 的 `cdxIconLogIn`，將操作移入草稿箱。草稿箱以「操作類型 · 用戶名 · 條目 · 規則」的 checkbox 列表多選恢復；每筆操作類型搭配對應的彩色圖標，區分新提名、編輯提名、核對分數及分數覆核，取出的內容移回表單；恢復後取消也會丟棄，想保留可再次暫存。草稿箱也可直接刪除選取項目。
- **共同編輯狀態：** 自動保存與草稿箱分開。正在編輯的表單以 localStorage 為準，同站點、同帳號的分頁同步展示。本地自動保存保留原輸入框與瀏覽器的撤銷／重做歷史，只有需要恢復或外部值確實改變時才回寫欄位；輸入法組合期間延後保存與影響輸入的更新，確認文字後再同步。不同欄位的修改會合併，同一欄位有衝突時保留兩份內容供選擇。本機保存失敗會保留畫面上的輸入、停用送出，並提供重試保存。
- **規則彈窗：** 前四類與已有選項的分類展開，其餘預設摺疊。每條規則保留自訂文字與分數欄位。彈窗內的修改只在按「完成」後套用到表單；取消、Esc 或中途重新載入都捨棄未確認修改。取消勾選規則仍會重設該規則的自訂值。
- **完成狀態：** 新提名沿用 [Codex 色板](https://doc.wikimedia.org/codex/latest/style-guide/colors.html)的 Blue 700（`#36c`）；修改提名用青綠色（`#177878`）、核對分數用黃綠色（`#4d7a1f`），兩者由原本的 Green／Lime 調整色相以提高辨識度；分數覆核另用 Yellow 700（`#886425`）。懸浮條上邊緣的進度條先排已完成的四種深色，再排未完成的四種淺色，兩組均依新提名、修改、核對、覆核排列，各塊寬度按全部操作筆數計算。八塊以相同緩動同步伸縮，連續操作會從當下寬度接續。文字區用彩色圖標與一般文字色顯示各類完成數，1/1 也顯示 100%。表單一開啟，同一筆提名的兩行（包含條目欄）就顯示連續的橫向漸變背景，核對單元格保留類型圖標：新提名用 `cdxIconUserAdd`、修改提名用 `cdxIconEdit`、核對分數用 `cdxIconHighlight`、分數覆核用 `cdxIconSandbox`。操作完成後，背景改為同色系的淡純色，圖標保持不變。頁面上的編輯、核對與覆核按鈕也沿用各自的操作色。已有有效核分結果（包含零分）即算覆核，懸浮條與送出確認分別列出核對及覆核筆數。未全部完成時「送出全部」置灰；暫時做不完的操作可以暫存或取消。
- **核對與覆核：** 逐筆按「核對」加入表單，無須另進多選模式。勾選「核對完成」後才準備送出，修改內容會撤銷完成標記。更正得分者時預覽扣回舊帳號及加入新帳號的實際差額；舊結果與簽名保留並標記撤銷。缺少入帳記錄的舊核分提供積分資料及歷史入口供查證。
- **送出確認：** 「送出全部」開啟二級面板，「確認送出」才真正儲存。面板顯示操作筆數、編輯摘要，以及存在新提名時才展示的整批提名說明。說明及摘要各自自動保存，不隨單筆操作進出草稿箱，也不自動拼接說明。
- **分步儲存：** 登記處、積分榜分別展示完成與失敗結果。首次確認送出依序執行；失敗後每次查詢或重試只處理指定步驟。結果未明時只查證原請求，避免重複加分。確定尚未寫入時可返回修改；部分成功或結果未明時保留待處理紀錄。
- **衝突處理：** 提交前及登記積分前再次比對來源。變更會中斷提交並顯示可讀的欄位差異，重新載入會保留本地修改及先前核對提案，要求重新確認。只有本次成功提交的對應內容會清除，其他分頁稍後新增的輸入仍保留。
- **完成回饋：** 儲存成功後直接更新頁面正文。「關閉」只關閉結果介面，另有「關閉並重新載入頁面」。
- **自己的提名：** 登入者是提名人或得分者時不顯示核對入口，提交時再次檢查。已核分項目透過覆核入口處理，不讓鉛筆按鈕暗中轉換成核對。
- **歸檔：** 章節內最新的 UTC 時間戳距現在未滿七天時，歸檔文字顯示灰色並提供懸停說明，點擊仍開啟歸檔確認。分別保存「追加存檔頁」與「移除登記處小節」的進度。第二步失敗只重試移除；小節或存檔內容有變時停止，不重複追加，也不移除後來新增的內容。

跨分頁協調需要瀏覽器支援 Web Locks 及 localStorage。圖標以 Wikimedia Codex SVG 隨 bundle 內嵌，不載入 webfont。

小工具會在提名內容及 `Module:ACGaward/list` 的註解中保留提交識別與入帳紀錄，用於覆核、逾時確認及避免重複加分。手動維護時請保留這些註解。登記處與積分榜是兩次獨立編輯，部分成功時可恢復尚未完成的步驟。

## 使用方式
### 發行版本
将如下程式碼复制至 [User:你的用戶名/common.js](https://zh.wikipedia.org/wiki/Special:MyPage/common.js) 頁面：

```js
importScript('User:SuperGrey/gadgets/ACGATool/main.js');  // Backlink: [[User:SuperGrey/gadgets/ACGATool]]
```

### 從原始碼建構

1. **安裝 Node.js**
   - 請先安裝 [Node.js](https://nodejs.org/)。

2. **安裝依賴套件**
   - 在 ACGATool 目錄下執行：
     ```sh
     npm install
     ```

3. **建構 Bundled 版本**
   - 執行下列指令以產生 `dist/bundled.js`：
     ```sh
     npm run build
     ```
   - 若需持續監看檔案變動並自動重建，請執行：
     ```sh
     npm run watch
     ```

4. **安裝至維基**
   - 將 `dist/bundled.js` 上傳至你的維基用戶頁面，例如 [User:你的用戶名/ACGATool.js](https://zh.wikipedia.org/wiki/Special:MyPage/ACGATool.js)。
   - 在 [User:你的用戶名/common.js](https://zh.wikipedia.org/wiki/Special:MyPage/common.js) 頁面加入：
     ```js
     importScript('User:你的用戶名/ACGATool.js');  // 修改為你的用戶名
     ```

## 本機驗證

```sh
npm test
npm run build
```

`tests/` 使用 Node.js 內建測試工具，集中檢查批次定位、覆核差額、跨分頁合併、暫存與遷移、混合提交、部分失敗、單步查證／重試及歸檔恢復。全部為 dry-run：測試啟動時禁止網路及真實 `mw.Api`，儲存流程僅使用注入的記憶體模擬介面，不會儲存維基頁面。
